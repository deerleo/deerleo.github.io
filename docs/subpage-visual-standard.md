# 二级、三级页面视觉规范

适用范围：教程首页、教程详情、项目/产品介绍及其方法论、案例等相对独立的二级与三级页面。首页主站导航和沉浸式互动应用内部控件不属于本规范的页面头部。

## 页面头部

- 使用 `_includes/subpage-shell.html`，并加载 `assets/css/subpage-shell.css`；所有页面共用同一组件和样式，禁止各页另造顶部品牌栏。
- 左侧主视觉使用本页所属教程、项目或产品名称。独立内容页不以「迷鹿 MiLu / milulab」替代内容名称；需要时可将课程名作为主行、章节或分类作为小字副行。
- 右侧提供低强调的「⌂ 首页」入口，固定返回站点根路径。返回上级目录/课程的链接可作为页面正文内的辅助路径，不替代首页入口。
- 顶栏采用半透明深色底、细分隔线、轻模糊效果；高度约 58px，内容最大宽度约 1180px。移动端收紧间距，品牌名不得被导航挤压。

## 页面页脚

- 统一使用 `subpage-footer`：内容区域对齐页面主栏，顶部细分隔线，低对比文字。
- 保留该页面必要的来源、版本、作者或关联链接，但品牌署名不抢占主视觉，也不重复显示为主标识。

## 落地与维护

Jekyll 页面引用：`{% include subpage-shell.html identity="教程/项目名称" descriptor="章节或类别" %}`，并在 `<head>` 引入 `{{ '/assets/css/subpage-shell.css' | relative_url }}`。页脚使用 `<footer class="subpage-footer">…</footer>`。

新增或改版二级、三级页面时必须引用本组件和样式；如页面有本地章节导航，将其放在内容区顶部或组件扩展槽中，不改变身份名称与弱化首页入口的层级。沉浸式实验台可以保持操作控件专属布局，但返回首页入口仍须清晰可用。
