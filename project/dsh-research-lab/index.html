框架架构：六层解耦

先有真实计算与复现，再有交互与炫技——每一层都可以独立替换。

交互层
DSH web / TUI / headless · CLI 直跑

课堂上可直接 python examples/.../run_t1_t5.py，也可让 DSH 智能体驱动同一套工具。

Preset 层
三个科研台预设

research-lab 通用 / edu-research 教育 / health-research 公卫——守则 + Skills + Tools 清单，换学科=换配置。

Skill 层
8 通用 + 4 领域技能

研究设计、数据导入、质量决策、探索分析、统计建模、模型验证、科研报告、证据溯源 + 教育泄漏审计等。每件都有适用条件 / 输入契约 / 验证条件 / 失败处理。

Tool 层
Python 计算层（stdout-only-JSON）

data_audit · regression · classification · stat_tests · report_builder——语言模型不碰数字，只调度与解读。

知识数据层
领域知识 + 数据包规范

domain.yml + methodology.md（知识带性质标注）+ 协议 protocol.md（先于分析锁定）+ 变量字典 + expected/ 数值锚点。

验证层
verify.py：49 项三方对账

SHA256 完整性 → 确定性复跑 → 双独立实现交叉验证（statsmodels vs 手写 OLS 逐位一致）→ 协议断言。CI 三平台 × 双 Python 版本背书。

五条教学铁律（框架内置，不可绕过）

🔒 原始数据只读

datasets/*/raw/ 永不改写，SHA256 锁定于 metadata/source.yml；改动立即被 verify 抓住（有专门的安全测试）。

🧮 数字只能来自真实执行

模型不得生成任何 p 值 / R² / AUC——那叫编造。全部统计值出自 tools/ 计算层。

⚖️ 双实现互证

每个头条指标有第二条独立实现路径：手写 OLS vs statsmodels（|Δ系数|=0）、秩和法 AUC vs sklearn。

🚫 因果表述禁令

观察性数据只谈关联；健康数据禁用于真实临床。不适用方法（生存/纵向/因果/调查加权）显式声明理由。

🛑 缺列即拒绝

数据不满足契约时，智能体必须提出修正要求——拒绝编造是 Skill 层的显式条款，课堂现场演示。

📋 协议先于数据

research-design 先出 protocol.md，分析计划锁定后不得静默修改；改协议必须升版本号。

桌面端：开箱可用的完整科研台

一个 .app 装下全部——随包内置真实 DSH（DeepSeek Harness 0.2.1-rc.2，npm 官方包原样分发）、 Node 22 运行时与全部 Python 科研栈；使用者无需预装 Node / Python / DSH。 从 Releases 下载 v0.3.1 dmg （或 .zip）即可安装。

🧩 内置真实 DSH

工作台一键启动 DSH Web（MIT 许可，整包未修改）： 12 个科研技能首启自动装配，所选科研台的智能体守则经 profile patch 注入会话； 会话内 DSH 的 shell 工具直接调用随包 Python 运行管线脚本。

🔐 模型 Key 本机配置

首次使用在「模型设置」填 Key（DeepSeek 官方或 OpenAI 兼容端点）。Key 仅存本机（0600），经环境变量注入 DSH——绝不打包、不写日志、不随应用分发。

📊 一键管线与产物

教育 / 公卫管线一键运行，报告、表格、图表就地浏览； 数据与产出全部落在用户目录，升级应用不触碰已有结果。

✅ 构建即验证 + 实机报告

构建自动做干净环境冒烟（装配 → 双管线真实产出 → 启动内置 DSH → token 断言 303/401，6/6 步全绿）；另附 GUI 实机验证与 preset 注入实证报告 docs/desktop-validation.md。

定制你自己的学科科研 Agent：七步法

改造而非重造——tools/ 与验收设施零改动，只换"知识 + 协议 + 数据"三件事。

1
验收即底线"回答像专家"不是标准；设计可识别、执行真实、坏数据处理有痕、复算一致才是。
2
tools 一行不改计算层全复用——新学科只需四件配置：domain.yml / 协议 / 字典 / Skill。
3
锚点即教材expected/ 里每个数字同时是回归测试基准与课堂事实锚点。
4
换数据可复用框架级验收项：用第二份数据证明"真实复用"而非"复制粘贴结果"。

快速开始（按场景分层）

方式 A｜macOS 桌面端（推荐——零环境依赖，开箱可用）

  1. 下载安装：dsh-research-lab-0.3.1-darwin-arm64.dmg（或 .zip）， 打开后把 DSH Research Lab.app 拖入「应用程序」；
  2. 首次放行：产物未公证——在「应用程序」中右键 → 「打开」→ 再点「打开」（macOS 会记住许可，之后正常双击）；
  3. 配置模型：点「⚙ 模型设置」填 API Key（DeepSeek 官方或任意 OpenAI 兼容端点）， 并选择科研台 Preset（edu-research / health-research / research-lab / none）； Key 仅存本机（0600），经环境变量注入 DSH；
  4. 开跑：点「▶ 运行」跑通双管线（真实数据约 10 秒）浏览报告；点「▶ 启动 DSH」 在真实 DSH Web UI 里以所选科研台守则 + 12 个技能驱动智能体， 会话内 python 直接命中随包科研依赖。

方式 B｜源码安装（教师 / 研究者，需 Python 3.11+）

# 跑通教育科研管线（真实数据，约 10 秒）
git clone https://github.com/milulab/dsh-research-lab.git
cd dsh-research-lab && pip install -r requirements.txt
python examples/education-demo/run_t1_t5.py   # → outputs/{results.json, report.md, …}
python examples/health-demo/run_h1_h5.py      # 公卫分类管线
python scripts/verify.py                      # 49 项对账全绿

方式 C｜接入已有 DSH（开发者 / 高级用户）

# 已安装 DeepSeek Harness（npm i -g @deepseek-ai/dsh）的场景：
bash scripts/install.sh --preset research-lab   # 装配 skills + 科研台 preset
dsh web                                          # 工作区指向仓库根目录

常见使用方式

  1. 课堂演示：桌面端一键跑 T1–T5 / H1–H5 管线，用产物里的 report.md 与图表讲"数字从哪来"；
  2. 智能体分析：在 DSH 会话里让智能体按科研台守则驱动同一套 tools/——模型只调度与解读，不碰数字；
  3. 学科定制：复制 templates/new-domain 七步换出自己的学科 Agent，换第二份数据复用整体验收。
