Domain Methodology · Education

学习行为与学业成绩的关联研究

以 UCI Student Performance（id=320）为基准数据：葡萄牙两所中学、葡语课 649 名中学生 × 33 字段，真实公开数据（CC BY 4.0）。研究对象是高校教师学员—— 本域教的是教育科研方法本身，不是"预测学生"。

T1–T5 预登记协议流程

协议 V1.0 先于分析锁定（datasets/education-student-performance/protocol.md）；分析计划不得边看边改。

T1数据导入与字段语义核查

分号解析 + 逐列类型断言 + 缺失/重复审计。raw 字节级检查发现 G1/G2 取值带引号——标准解析器静默吸收为整数，类型异常就此消失。引号数字是解析层必须显式核查类型的原因。

教学点：引号数字 → 静默类型漂移 → "解析层不得信任推断"三段论，是 data-intake 技能的核心案例。

T2单变量关联 + 组间检验（只表述关联）

有序暴露用 Spearman（ρ：studytime +0.2747、failures −0.4484）；absences 双口径对照（Pearson −0.0914 / Spearman −0.1585）；两独立组 Welch t + Mann-Whitney + Cohen's d（sex：d=−0.264）；Medu 五组 Welch ANOVA（F=9.85）；卡方 + Cramér's V（school×higher V=0.131，含期望频数检查）；8 项检验家族 Bonferroni / BH-FDR 双校正。

T3多变量回归 M1 与诊断

协议公式 G3 ~ C(school)+C(sex)+Medu+Fedu+studytime+failures+absences： 调整 R²=0.2629；studytime +0.511 [0.239, 0.783]；failures −1.667（p≈2e-17）。 诊断三件套真实存在：BP 显著（异方差）→ 必报 HC3 稳健 SE；JB 拒绝正态（偏度 −0.84）； VIFmax=1.80 无共线；设计矩阵满秩；Cook's d >4/n 共 60 例（报告而不删除）。

T4目标信息时点对照（泄漏审计）

M2 = M1 + G1 + G2 → 调整 R² 0.2629 → 0.8500（Δ+0.587）。 解读纪律：M2 回答"期末解释/含泄漏预测"，不是"更好的模型"；回答研究问题的只有 M1。 教育数据几乎总含期中成绩——这是该领域最常见、最隐蔽的泄漏源。

课堂金句：如果论文里出现这种解释力跳变，先问"预测在什么时点可用"，而不是先庆祝。

T4b连续预测与解释

80/20（seed=42）holdout MAE=2.20 / RMSE=2.826 / R²=0.226；5 折 CV R² 均值 0.2377； 置换重要性（r² 计分，30 次重复）给出"哪些变量真正贡献样本外预测"。

T5复现交付

results.json（全量结构化）+ report.md（人读）+ tables/ + figures/ + 运行日志； 双实现互证：statsmodels vs numpy 手写 OLS |Δ系数|=0（逐位一致）； python scripts/verify.py --suite education 一键对账。

课堂讲点（教师速查）

🧲 为什么是"中学数据"？

授课对象是高校教师，研究主题是教育科研方法。数据真实性、变量语义（studytime 分档、failures 上限封顶 4）、重叠样本（382 名学生两课都有记录，禁合并当独立样本）——每一条都是真实科研会遇到的问题。

🗣️ 措辞边界训练

全部结论用"关联/一致/提示"；"证明/导致/效应"在观察性设计里不出现——报告生成器从 JSON 引用数字时同步执行这一纪律。

🔁 换学科怎么迁

tools/ 零改动；换协议 + 字典 + Skill + expected/ 锚点即可。迁移自检：用第二份数据证明"真实复用"而非"复制结果"。

不适用方法（显式声明，防方法错配）

生存分析（无时间-事件字段）· 纵向/混合模型（无重复测量）· 因果效应估计（观察性无识别策略）· 调查加权（非复杂抽样）· 序数 Logistic 作主模型（G3 近似连续，OLS 为协议主模型，序数模型仅课后扩展）
