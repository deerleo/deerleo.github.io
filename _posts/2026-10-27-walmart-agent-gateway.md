上个月，Amazon 把 Meta 的购物 Agent 拦在了门外。据 TechCrunch 报道，理由有三条：没提前通知、不亮明身份、疑似存了客户凭证。Meta 否认。

这个月，沃尔玛朝反方向迈了一步。10 月 21 日官宣 Agent Gateway：一个正经的 MCP 服务器，让守规矩的 Agent 进来搜商品、加购、下单、查订单。beta 入口开在 walmart.com/agents，Walmart 和 Sam's Club 两个品牌都覆盖，不需要会员。

很多解读把这讲成"开放对封杀"。我不这么看。Amazon 自己也有自营的 Buy for Me，同样自报身份，品牌还可以选择退出。真正的分歧只有一个：给不给守规矩、自报身份的 Agent 一个官方入口。沃尔玛给出了答案，而且这份答案的工程质量，比想象中高。

## 当架构图来读

我把它当一份设计稿拆了一遍。四道锁。

第一道锁，统一入口。所有 Agent 的购物动作都从 Agent Gateway 这一个 MCP 服务器过：搜库存、加购、下单、查订单。MCP 是 Anthropic 发起的开放标准，白话讲，就是给 AI 应用调用外部工具定的一套通用插座——Agent 侧按标准插，平台侧一个口收。我自己是 MCP 重度用户，天天在用，看到沃尔玛选它不意外：不用跟每家 Agent 厂商单独谈集成，流量、审计、风控全在一个口子上。

对了，一个让我会心一笑的细节：官方公告里把 MCP 展开写成了 model text protocol，正确的全称是 Model Context Protocol。几千亿美元营收的公司，发布公告也会手滑。这种细节让我对它多了一点亲切感。

第二道锁，身份隔离。官方说下个月上线 Agent Profiles：每个 Agent 在客户账户里有一份独立档案，首次使用自动创建，购买记录单独展示，客户随时可以整份删掉。官方给的类比很妙，像在信用卡上加一个授权持有人。隐私的边界也画了：Agent 可以知道你常买哪个牌子的牛奶，拿不到你的完整购买历史和个人信息。

第三道锁，额度风控。默认逐笔批准，每一单都要客户点头；嫌烦的可以设消费上限，官方给的例子是 50、100、200 美元。但注意原话留了个活口：即使在限额内，沃尔玛也可能要求额外批准。什么条件触发，没说。这张入场券是有条件的。

第四道锁，条款与封禁。随 Gateway 一起发布的还有一份 Terms for AI Agents，核心就几条：Agent 不得越出购物者的意图；不碰支付卡信息，不能增改支付方式；只访问任务所需且客户允许的信息；不守规矩的，直接封出沃尔玛网站。还有一句我印象很深：We price products, not people。Agent 看到的价格和 Walmart.com 一模一样，没有"机器专属价"。

## 你要抄的话

四道锁对应四件能直接抄的事。收口，别让 Agent 直连你的后端，一个标准入口进。身份，每个外部 Agent 一份独立档案，行为可归属到具体主体。额度，默认逐笔授权，信任攒起来了再放限额。条款，把不可做的事写进协议，违规有明确代价。

照抄之前，有两个坑是文档里看不到的。

一是准入。Agent 怎么"获准"进这个 beta，官方一个字没提。门票怎么发、发给谁、收不收费，全是黑箱。你抄这套架构的时候，这道门得自己设计。

二是误伤。据报道，10 月初 Meta 的 Muse 在沃尔玛结账时被人机验证按钮卡住，中断就被踢出流程，沃尔玛说不是有意拦截。自家反爬虫误伤了别人家的 Agent。开放和防御的边界，在条款页上很好画，在真实流量里很难画。

还有一组数值得放在心上。一项对 1000 名美国成年人的调查（NMI）：11% 的人用 AI 完成过交易；70% 希望购买前有审查或否决权；只有 10% 愿意把购买决定完全交给 AI。沃尔玛的逐笔批准加限额，本质上是把那 70% 的顾虑做成了产品功能。

## 入口的胜负手

Agent 商业化这场仗，胜负手不在模型多聪明，在入口谁先做好。谁能先给出平台放心、用户放心、Agent 开发者也放心的三方接口，谁的生态就先跑起来。沃尔玛这四道锁，是我目前看到的最完整的一版参考答案。

下一篇从沃尔玛往上看一层：Anthropic 的 S-1 里，163 亿营收对着 807 亿净亏。这账怎么读，是每个关心 AI 公司的人都该会的。
