老话说，买刀要去铁匠铺，别在地摊上捡。

图省事在线上市场装扩展的人，想法也差不多：官方渠道、官方账号、官方名字，总归干净。10 月 29 日上午，这个想法被打了个响亮的耳光——Cursor 的 VS Code 扩展市场里，那个名叫 `Anthropic.claude-code` 的正版扩展，被塞进了后门。

不是高仿，不是蹭名字的山寨货。是正主账号、正主名字、正主的下载渠道。

## 你以为装的是工具，装的是钥匙

事情的经过不复杂。10 月 29 日太平洋时间凌晨 2:27 到下午 1:35，前后大约 11 个小时，Cursor 市场里的 Claude Code 扩展悄悄换上了 2.1.312 和 2.1.313 两个「新版本」。开着自动更新的编辑器，一声不吭地帮你完成了升级。

新版本里多了大约 66 行 JavaScript，插在正常代码前面。它干了三件事：

把你的主机名、用户名、Git 邮箱、公网 IP 打包上报——顺带扫一眼你机器上带 KEY、TOKEN、SECRET、PASS 这些字样的环境变量，最多扫 40 个。注意，只拿名字，不拿值。名字本身就够意思了：它等于告诉你，这台机器上放着哪家云的钥匙、什么类型的凭证。

往你的 `~/.ssh/authorized_keys` 里追加一把攻击者的公钥，标签起得特别人畜无害，叫 `svc-telemetry`——遥测服务，听着就像是个正经运维该有的东西。

最后，尝试开你机器的 SSH 服务、建一条反向隧道直通攻击者的服务器，再往 macOS 的 LaunchAgent、Windows 的计划任务里写持久化，重启也不丢。

![Cursor 编辑器界面：写代码的人和 AI 编程工具已经深度绑定，工具链一旦被污染，波及的就是整条开发流水线](/assets/images/2026-11-01-cursor-claudecode-supply-chain/cursor-ui.jpg)

Cursor 事后公告里有个细节值得单拎出来：开 SSH 服务需要管理员权限，恶意代码在这步大多数情况下会失败。也就是说，攻击没完全得手——但密钥已经装进去了，持久化已经埋进去了，你的机器信息已经在攻击者的数据库里了。败仗打了一半，剩下的另一半是时间问题。

## 该抬的得抬：这口锅不是 Anthropic 的

先把话说公道。这次进后门的扩展，正主没有被黑。

Anthropic 的官方 npm 包没事，微软官方 VS Code 市场的版本没事，出事的只有 Cursor 市场这一条分发渠道。Cursor 自己也认账：发现后立刻下架，干脆把整个市场关了重建，轮换了密钥，审计确认没有其他扩展被篡改，还联合云厂商把攻击者的服务器下线了。从响应速度讲，这套动作没得挑。

Cursor 估算，最多约 5000 名用户收到了恶意版本。怎么发出去的，目前没有公开答案——公告里只说恶意版本「并非 Anthropic 开发」，账号本身是 Anthropic 员工的合法账号。是账号被钓鱼，是发布令牌泄漏，还是市场侧被入侵，谁也说不准。

而这个说不准，正是最让人睡不着的地方。

## 说到底，「官方」两个字是怎么保鲜的

![电路板上的挂锁：供应链安全的全部难点在于，你锁得住自己的代码，锁不住别人的分发管道](/assets/images/2026-11-01-cursor-claudecode-supply-chain/supply-lock.jpg)

开发者为什么信市场？因为市场承诺替你干了最难的那件事：验证发布者是你以为的那个发布者。

这次事故把这句话拆穿了。工具是正的，名字是正的，市场是官方的，一个恶意构建照样溜进去——Coralogix 的研究员说得很直白：**一个扩展的可信度，取决于整条发布链上最弱的那个环节**。账号安全、令牌管理、构建管线、市场审核，任何一环松了，「官方」就过期了。

更微妙的是时机。就在同一周，开源模型攻破 Firefox 补丁空窗期的报告刚发出来，AI 自己找漏洞写攻击代码的成本已经降到千美元级。这意味着攻击者的选项越来越多：可以像这次一样打人的信任链，也可以让模型去打代码的漏洞链。防御方要守的面，肉眼可见地在变大。

Morphisec 的 CEO Ron Reinfeld 总结得挺到位：「工具是真的，发布者的名字是真的，市场是官方的。一个恶意构建就能把受信任的 AI 编程助手变成后门投递器。」他还补了一句更狠的：**「AI 工具没有任何正当理由去写 SSH 密钥、开反向隧道。组织需要管控的是这些应用跑起来之后能干什么，而不是只管它允不允许跑。」**

这句「跑起来之后能干什么」，值得每个装了 AI 工具的人想三秒。

## 咱能做的三件小事

判决落回自己身上，就三件事，今天就能办：

查一下自己中没中招：`grep svc-telemetry ~/.ssh/authorized_keys`，有输出就说明中了，按 Cursor 公告的脚本清干净。顺手看看有没有陌生的 LaunchAgent 和计划任务。

以后扩展更新，关掉自动更新。Cursor 那批用户就是被自动更新放倒的——你睡觉的时候，后门自己进来了。

最根本的一条：官方渠道装的东西，默认它可能会出事。AI 工具要的权限越来越多，能碰的东西越来越值钱，「它叫这个名字」不再是安全边界。想想它在你机器上能干什么，再想想你愿不愿意承担那个后果。

工具越强，越要看紧它。这跟养狗一个道理——狗越壮，绳子越要握在自己手里。
