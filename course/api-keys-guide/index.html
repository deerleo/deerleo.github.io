① 先花 3 分钟搞懂 API Key

API（Application Programming Interface，应用程序编程接口）是程序之间对话的约定；API Key（API 密钥）就是你在某家平台上的「调用凭证」——平台靠它识别请求来自谁的账户、该向谁扣费。

?

一句话原理

你的程序带着 Key 发请求 → 平台校验 Key、按用量扣费 → 返回模型生成的结果。所以 Key 等同于账号密码：谁拿到它，谁就能花你账户里的钱。

≠

② DeepSeek

预计耗时约 10 分钟（不含充值）

DeepSeek 的开发者平台（platform.deepseek.com）和聊天端（chat.deepseek.com）是两套账号体系——API Key 只能在开发者平台申请。

1

打开开发者平台，注册并登录

浏览器访问 platform.deepseek.com，用大陆手机号 + 验证码注册，或直接微信扫码登录。

⚠️ 坑点：别进成 chat.deepseek.com——那是聊天端，注册了也申请不了 API Key。
2

左侧「API keys」→ 创建 API key

登录后进入控制台，左侧菜单点「API Keys」，再点右上角蓝色按钮「创建 API key」，可给它起个名字方便日后区分。

3

立即复制密钥——只显示这一次

创建成功后会弹出 sk- 开头的完整密钥，关掉弹窗后就再也看不全了。当场复制，存进环境变量（见第 ⑤ 节）。

⚠️ 坑点：没保存下来怎么办？——只能把这条 Key 删掉重新创建，旧 Key 立即失效。整个补救过程 30 秒，别慌。
4

充值（几块钱就能开始学）

左侧菜单「充值」→ 选金额 → 支付宝 / 微信支付。DeepSeek 无长期免费额度，余额为 0 时调用会报 402 错误；学习用途充 10 元以内足够跑很久。

5

首次调用

DeepSeek 接口与 OpenAI 格式兼容：把 base_url 指到 https://api.deepseek.com，带上你的 Key 即可。当前官方文档示例模型为 deepseek-flash（更强的对话模型有 deepseek-v4-pro），实际以官方文档为准。

# 密钥放环境变量，不写进命令历史 export DEEPSEEK_API_KEY="sk-你的密钥" curl https://api.deepseek.com/chat/completions \ -H "Content-Type: application/json" \ -H "Authorization: Bearer $DEEPSEEK_API_KEY" \ -d '{"model":"deepseek-flash", "messages":[{"role":"user","content":"你好"}]}'
💡 会写代码的话更简单：pip 装好 openai 库，把 base_url 改成上面的地址、api_key 读环境变量，其余写法和调 OpenAI 一模一样。
报错含义处理
401 Unauthorized密钥无效：没带上、复制错了，或 Key 已被删除检查环境变量是否生效，必要时重建 Key
402 Payment Required账户余额不足去「充值」页充值后再调用
429 / 超时触发限流或网络超时稍等重试；连续出现可降低并发

③ 通义千问 · 阿里云百炼

预计耗时约 15 分钟（含实名认证）

百炼（Model Studio）是阿里云的大模型服务平台，通义千问（Qwen）系列模型从这里调用。实名认证是硬性门槛：不实名就无法开通服务、无法调用。

1

注册阿里云账号并完成实名认证

先在 aliyun.com 注册账号，然后进入「实名认证」：个人认证用支付宝授权 / 扫脸，即时生效；企业认证需营业执照，约 1–3 个工作日。

⚠️ 坑点：实名没做完，后面百炼的开通按钮都是灰的。先花 2 分钟把实名清掉，别反反复复撞墙。
2

进入百炼控制台，开通服务

访问 bailian.console.aliyun.com，首次进入按提示免费开通服务（按 token 用量计费，开通本身不收费）。

3

右上角头像 →「API-KEY 管理」→ 创建

创建前先在页面右上角选好地域（常用「华北2 - 北京」），再点「创建我的 API-KEY」。创建成功后密钥仅完整显示一次，立即复制。

⚠️ 坑点：每个地域的接入域名、API Key、模型列表相互独立、不能跨地域混用——用北京的 Key 打上海地域的域名会直接报错。教程统一按「华北2 - 北京」走。
4

（可选）配置权限与业务空间

创建时可选归属业务空间与授权范围：默认「全部模型可用」，也可自定义——限定可用的模型范围、设置 IP 白名单。多人协作或多项目并行的团队建议分 Key 管理，泄露哪个吊销哪个。

5

领取免费额度

控制台里的「免费额度」页可以按模型一键领取新用户体验额度（按 token 计量，通常有 90 天有效期，过期作废）——先领再跑，能省一笔。具体额度以控制台实时展示为准。

6

首次调用

北京地域的 OpenAI 兼容地址是 https://dashscope.aliyuncs.com/compatible-mode/v1，常用入门模型 qwen-plus（环境变量名各家惯例：DASHSCOPE_API_KEY）。模型名与各地域接入点以官方文档为准。

💡 换平台 = 只改三处：base_url、模型名、API Key。代码结构一行都不用动——这也是三家都走 OpenAI 兼容格式的好处。

④ Kimi · 月之暗面开放平台

预计耗时约 10 分钟

Kimi 的开放平台（platform.kimi.com，旧域名 platform.moonshot.cn 仍可访问）和聊天端（kimi.com）是两套入口——API Key 在开放平台的控制台申请。

1

打开开放平台，注册登录

访问 platform.kimi.com，用中国大陆手机号（+86）注册登录。

⚠️ 坑点：海外手机号注册可能受阻；另外别进成聊天端——聊天会员和 API 账户是分开的。
2

完成实名认证

进入控制台后按提示完成实名：个人认证用身份证，通常即时通过；企业认证约 1–3 个工作日（以平台内提示为准）。未实名无法正常使用开放平台服务。

3

控制台「API Key 管理」→ 新建

左侧菜单进「API Key 管理」，点「新建 API Key」，填一个名字（如 my-first-key），确认后立即复制完整密钥——同样只显示一次。

4

费用中心确认体验金

新用户通常会自动到账一笔体验金 / 代金券（金额与有效期以控制台为准，常见如 15 元 / 30 天）。先到「费用中心」确认到账和到期时间再开跑——过期作废。

5

首次调用

OpenAI 兼容地址 https://api.moonshot.cn/v1（环境变量惯例名 MOONSHOT_API_KEY）。当前旗舰模型为 kimi-k3.1-pro，实际以开放平台「模型列表」页为准。

⑤ 密钥安全：四条底线（三家通用）

API Key 就是账户密码：泄露 = 别人花你的钱、用你的额度跑任意任务。下面的规矩三家通用，2 分钟养成习惯。

1

只存环境变量，不写进代码

代码里只出现变量名，实际值放在终端环境或系统变量里；这样密钥不会被写进代码仓库、截图和聊天记录。

⚠️ 坑点：把 Key 硬编码进代码再推上 GitHub，是密钥泄露的第一大来源——爬虫几分钟内就会扫到并盗用。万一推了：立即删 Key 重建，并清理提交历史。
2

按项目 / 按环境分开建 Key

学习、工作、demo 各用各的 Key。哪条泄露了，吊销哪条就行，不影响其他项目。

3

不进仓库、不发群聊、不截图外传

包含 .env 文件加入 .gitignore；发求助帖先打码；给别人部署服务时用对方的 Key，不共享你的。

4

怀疑泄露，立即删除重建

到对应平台的 Key 管理页删除旧 Key、创建新 Key，全程 30 秒。旧 Key 立即失效，损失就此截断。顺手开启平台提供的余额告警（如有），钱花超会提醒你。

⑥ 常见问题

三篇教程走完后最常被问到的几件事。

Key 丢了 / 没保存下来怎么办？

找回不可能（平台只显示一次），补救很简单：到 Key 管理页删除旧 Key → 新建一个 → 立即复制保存。旧 Key 马上失效，不用慌。

换一家平台，代码要改多少？

只改三处：① base_url（接口地址）② 模型名 ③ API Key（换成新平台的环境变量）。请求结构完全不变——三家都是 OpenAI 兼容格式。

计费怎么算，会不会跑爆账单？

按 token（可理解为字词片段）计量，输入与输出分开计价，各家定价页为准。先用小额度试跑，确认效果再放量；个人学习单日消耗通常不到 1 元。担心失控就开余额告警、只放小额预算。

401 / 402 / 429 分别是什么意思？

401 = 密钥无效（没带上、复制错、被删除）；402 = 余额不足（主要见于 DeepSeek，充值即可）；429 = 触发限流，稍等重试或降低并发。对照表见第 ② 节末尾。

能把自己的 Key 分享给同学 / 同事用吗？

不建议。账单混在一起、泄露面变大。正确做法：各自注册各自建 Key；给团队用则在平台内分项目建多个 Key，权限范围按需配置（百炼支持模型范围与 IP 白名单）。

聊天端账号和 API 账号是一回事吗？

DeepSeek 与 Kimi 的聊天端和开放平台是两套账号体系：聊天端充值买会员，开放平台充值调接口，互不相通。申请 Key 请认准 developer / platform / 开放平台入口。
