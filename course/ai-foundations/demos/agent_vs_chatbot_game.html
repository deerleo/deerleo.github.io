聊天机器人 vs 智能体

💡 核心区别

聊天机器人（如豆包、ChatGPT基础版）：只会说话，回答你的问题
智能体（Agent）：会做事，能帮你订票、发邮件、写代码、操作软件！

🔄 ReAct模式

ReAct = Reasoning（推理）+ Acting（行动）

智能体的工作循环：
思考 → 行动 → 观察 → 思考 → ...

例如：
🤔 思考：用户要订票，我需要查询航班信息
⚡ 行动：调用航班API
👀 观察：返回了3个航班选项
🤔 思考：用户没有指定时间，我需要询问
💬 回复：找到了3个航班，请问您偏好什么时间？
