Credits

T-Minus is a cooperative mission-design prototype made for NASA Space Apps 2026. The human team created the concept, designed the gameplay and directed development.

Development and artwork

All original project code was written with OpenAI Codex and Anthropic Claude. Project documentation and supporting copy were also AI-assisted. Fictional character portraits and Earth-and-satellite artwork were generated with ChatGPT Images and carry AI-generation labels. The game uses prepared content; it does not generate content with AI during play.
