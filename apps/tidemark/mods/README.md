# 潮汐战线：怎么写扩展

扩展可以给游戏加地图、加文字和语言、加指挥官、改兵种数值。一个扩展是一个文件夹，里面有一个 `mod.js`。

当前游戏版本：**1.0**（以 `AWMods.GAME_VERSION` 为准，标题画面左下角显示的就是它）。

## 怎么启用

1. 把扩展的文件夹放进 `mods/`。文件夹名就是扩展的 id，例如 `mods/sample-map/`。
2. 打开 `mods/mods.js`，把 id 写进清单：

   ```js
   window.AWModList = ['sample-map'];
   ```

   写了几个就启用几个，按清单的顺序加载。清单是空的，游戏就和没有扩展时一样。
3. 重新打开游戏。标题画面右下角会出现「扩展」标记，点开能看到每个扩展的名字、版本、加了什么。被跳过的扩展会写出原因。

想先试一下：把 `mods-examples/sample-map/` 整个拷到 `mods/sample-map/`，再按第 2 步写清单。

## mod.js 怎么写

```js
AWMods.register({
  id: 'sample-map',          // 必填。和文件夹名一样。只用小写字母、数字、连字符
  name: '示例地图：三岔河',   // 必填。显示在扩展列表里
  version: '1.0.0',          // 必填。扩展自己的版本
  gameVersion: '1.x',        // 必填。适用的游戏版本，写法见下
  author: '你的名字',         // 选填
  desc: '一句话说明。',       // 选填
  maps: [ ... ],             // 地图
  i18n: { en: { ... } },     // 文字
  langs: [ ... ],            // 新语言
  cos: [ ... ],              // 指挥官
  balance: { ... },          // 数值调整
});
```

`gameVersion` 的写法：

| 写法 | 意思 |
| --- | --- |
| `'1.0'` | 只适用 1.0 |
| `'1.x'` | 1 开头的版本都适用 |
| `'*'` | 所有版本都适用 |
| `['1.x', '2.0']` | 列出的任何一个对上就行 |

版本对不上的扩展会被跳过，游戏照常运行。

## 地图

写法和 `maps/` 里的文件一样。每张图是一个对象：

```js
maps: [{
  name: '三岔河',                       // 必填。地图名
  size: '14×10 · 两个阵营 · 小图',       // 尺寸后面的一句话
  blurb: '地图简介。',
  half: ['mf..c.v', 'fH.B..v', ...],    // 只画左半边，右半边自动转 180° 生成
  units: [['inf', 2, 1]],               // 一号阵营开局的部队：[兵种, x, y]，二号阵营自动对称
}]
```

两种画法选一种：

- `half`：只画左半边。右半边自动生成，两个阵营完全对称。最省事。
- `rows`：画整张图。二号阵营的建筑用 `p2: [[x, y], ...]` 标出，部队写在 `units2`。照 `maps/01-晨曦镇.js` 写。

每行是一个字符串，每行一样长。一个字符是一格：

| 字符 | 地形 | 字符 | 地形 |
| --- | --- | --- | --- |
| `.` | 平原 | `f` | 森林 |
| `m` | 山地 | `r` | 道路 |
| `b` | 桥 | `v` | 河流 |
| `~` | 海 | `e` | 沙滩 |
| `o` | 礁石 | `s` | 沼泽 |
| `u` | 废墟 | `w` | 荒地 |
| `#` | 墙 | `*` | 碎片堆 |
| `c` | 城市 | `x` | 兵工厂 |
| `a` | 机场 | `p` | 港口 |
| `t` | 雷达塔 | `g` | 陨星矿 |
| `h` | 医院 | `k` | 碉堡 |
| `i` | 导弹井 | `l` | 科研所 |

上面的建筑都是中立的。一号阵营开局就有的建筑用大写：`H` 总部、`K` 城市、`B` 兵工厂、`P` 机场、`S` 港口、`G` 陨星矿、`D` 医院、`F` 碉堡、`L` 科研所。每个阵营要有一个总部。

扩展的地图会出现在自由对局的地图列表里，简介后面标着「扩展：扩展名」。地图名和游戏自带的一样时，会换掉自带的那张。

## 文字

游戏里所有文字都以简体中文为原文。别的语言是「中文原文 → 译文」的对照表。

```js
i18n: {
  en: { '三岔河': 'Three Fords', '地图简介。': 'About this map.' },
  ja: { '三岔河': '三叉川' },
}
```

- 给自己的地图名、简介、指挥官名加译文：把中文原文当键写进去。
- 改游戏已有的译文：写同一个键，后加载的生效。
- 改简体中文的显示：写 `'zh-CN': { '原文': '新的说法' }`。
- 没有写译文的语言，显示中文原文。

语言代码：`zh-CN`、`zh-TW`、`en`、`ja`、`ko`、`fr`、`de`、`es`、`pt-BR`、`ru`。

## 新语言

```js
langs: [{ id: 'it', name: 'Italiano' }],
i18n: { it: { '开始': 'Inizia', ... } },
```

`id` 是语言代码，`name` 是语言菜单里显示的名字。没有翻到的地方显示中文原文。

## 指挥官

指挥官用游戏已有的效果拼出来。最快的办法：打开 `data.js`，找一位效果相近的指挥官（`D.COS` 里），照着改。

```js
cos: [{
  id: 'pk_ram',                 // 必填。小写字母、数字、下划线
  name: '撞角',                  // 必填
  title: '装甲先锋',             // 必填。名字下面的称号
  faction: 3,                   // 必填。阵营：1 赤焰、2 苍蓝、3 翠林、4 金沙、5 黑潮
  passive: '坦克攻击 +10%，步兵造价 −10%。',   // 必填。被动效果的说明文字
  power: '总攻',                 // 必填。指挥官技能的名字
  desc: '本回合全军攻击 +30%、移动 +1。',      // 必填。技能的说明文字
  mods: [{ on: 'tank', atk: 0.1 }, { on: 'inf', cost: -0.1 }],   // 被动效果
  fx: { atk: [{ on: 'all', v: 0.3 }], move: [{ on: 'all', v: 1 }] },    // 技能效果
  rules: { },                   // 特殊规则，选填
  good: ['tnk'], bad: ['inf'],  // 擅长和不擅长的兵种，只用来显示
  portrait: 'ram.png',          // 头像，放在扩展自己的文件夹里。选填
  lore: { quote: '撞过去。', bio: '人物介绍。' },   // 图鉴里的文字，选填
}]
```

说明文字要自己写，游戏不会按效果自动生成。

**`mods`（被动）**：每一项先用 `on` 选兵种，再写效果。

- `on` 可以写一类：`all` 全部、`inf` 步兵类、`land` 陆军、`vehicle` 车辆、`direct` 近战、`indirect` 远程、`tank` 坦克类、`tread` 履带、`wheel` 轮式、`air` 空军、`heli` 直升机、`plane` 飞机、`ship` 海军。也可以写兵种 id 的数组，例如 `['tnk', 'med']`。`not` 用同样的写法排除一部分。
- 效果：`atk` 攻击、`def` 防御、`cost` 造价（都是比例，`0.1` 是 +10%，`-0.1` 是 −10%）；`move` 移动、`vision` 视野、`range` 射程（都是格数）；`capture` 占领、`repair` 修理。
- 还有按地形或对手起作用的：`defOn`、`atkOn`、`repairOn`、`vs`、`counterAtk`、`counterCut`、`hold`、`carry`。这些照 `data.js` 里的例子写。

**`fx`（技能）**：技能开着的那个回合生效。

- `atk`、`def`、`move`：写成 `[{ on: 兵种, v: 数值 }]`。`on` 的写法和上面一样，`v` 是加多少（攻击、防御是比例，移动是格数）。
- `heal`：全军立刻回复多少生命（内部数值，10 是 1 点生命）。
- `ai`：电脑什么时候放技能。`'now'` 攒满就放，`'attack'` 够多的部队打得到人时放（不写就是这个），`'heal'` 回复量够多时放。
- 别的效果见 `data.js` 里 `D.COS` 上面的注释，照例子写。

**完整的字段清单**：在浏览器的控制台里运行 `AWMods.effectKeys()`，会列出 `mods`、`rules`、`fx` 现在能用的全部字段。写了清单里没有的字段，这个扩展会被跳过，并说明是哪个字段。

**头像**：`portrait: 'ram.png'` 只给一张图。要分场合就写 `portrait: { normal: 'a.png', power: 'b.png', lose: 'c.png' }`（平时、放技能、输了）。建议用正方形的 PNG，512×512 以上。不给头像时用游戏的默认头像。

扩展的指挥官在自由对局里直接可选。电脑也会用。

## 数值调整

```js
balance: {
  units: {
    inf: { cost: 900 },          // 步兵造价改成 900
    tnk: { move: 7, vision: 3 }, // 坦克移动 7、视野 3
  },
  damage: {
    inf: { tnk: 9 },             // 步兵打坦克的基础伤害改成 9（满生命打满生命时的百分比）
  },
}
```

- `units` 能改：`cost` 造价、`move` 移动、`vision` 视野、`range` 射程（`[最近, 最远]`）、`ore` 强化建造要的陨星碎片。
- `damage` 第一层是打人的兵种，第二层是挨打的兵种。只能改原来就有的格子。
- 兵种 id 见 `data.js` 的 `D.UNITS`。

数值调整对所有对局都生效，战役也是。

## 暂不支持

- 新兵种。
- 新的战役关卡。
- 新地形、新建筑、新科技。
- 全新的效果（现有效果清单之外的）。

## 几条规则

- **坏了只跳过自己**。文件找不到、字段写错、脚本出错，都只跳过这一个扩展，游戏和别的扩展照常运行。原因写在扩展列表里。
- **重名时后面的赢**。两个扩展有同名的地图或同 id 的指挥官，清单里靠后的那个生效，列表里会留一条说明。
- **存档记着扩展**。存档会记下当时启用的扩展和版本。读档时缺了其中哪个，这个存档就不能继续，游戏会说明缺哪个。存档不会被删：重新启用那个扩展，就能接着打。
- **战役进度照常**。启用了指挥官或数值调整这类改规则的扩展时，战役进度照常保存，标题画面右下角会一直显示「已启用扩展」。
- **只用本地文件**。扩展通过 `<script>` 加载，直接双击 `index.html` 也能用。扩展里不要联网读文件。

## 发布成包（选填）

想把扩展发成一个包，在文件夹里放一个 `package.json`。照 `mods-examples/sample-map/package.json` 写：

- `name`：`dsh-game-tidemark-` 加扩展的 id。
- `dsh.extends`：写 `dsh-game-tidemark`，说明它是这个游戏的扩展。
- `dsh.gameVersion`：和 `mod.js` 里的 `gameVersion` 一样。
- `dsh.modId`：扩展的 id，也就是放进 `mods/` 时的文件夹名。
