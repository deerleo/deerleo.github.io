### 2. 沙盘建模深改（Micro 级工艺密度）
- **程序化 DEM 地形引擎**：逐战场手工地貌参数（山脊线高斯脊 + 独立山峰 + 河谷下切 + 湖盆 + 海岸截断 + 平原碾压）在 200×N 网格上合成 → PlaneGeometry 236 段位移 + `applyExaggeration` 起伏实时重建（法线随动）
- **地貌着色 CanvasTexture（1024 宽）**：海/湖深浅分层 + 近岸浅水提亮 + 西北掠射山体阴影（×24 强化）+ 等高带微韵律 + 植被低频查表 + 林斑点缀（~1500-2200 簇）+ 河流三笔描线（晕影/暗床/亮芯，宽度按真实跨度换算）+ 岸线浪沫双笔 + 纸纹颗粒 + 四缘压暗 —— 测绘图版质感
- **海面自研波动 shader**：双向正弦波 + 近岸提亮 + 夜色压暗（uNight），仅滨海战场生成；水面高度取海岸实测高程
- **军团体系**：军种分形实例化方阵（inf 横阵 ×14 / cav 宽阵 ×8 / archer 列线 ×16 / knight 楔 ×6 / chariot 车列 ×5 / ship 纵队 ×3）+ 逐实例尺寸扰动 + 奇偶行明度差（instanceColor 打破色毯）+ 阵基薄台 + 军旗（旗杆+旗冠珠+CanvasTexture 纹旗，顶点 shader 随风摆动）+ 接地阴影贴片
- **战船 CatmullRom 放样船壳**（赤壁水战专用）：七点截面 × 四站放样（loftSections+loftSkin）+ Tube 弯管舷缘 + 舱楼 + 桅杆三角帆 + 靠旗；船队默认沿河切线朝向（riverYawAt）
- **营帐放样脊顶帐篷**（五点截面放样 + 布纹 CanvasTexture + 门脸 + 拉绳 + 篝火夜光点）；**城寨**（基座+屋舍群+角楼望灯）；**石墙分段随地形**（1.3u 分段贴地 + 墩台）；**夯土甬道**（巨鹿）
- **进军箭头丝带 shader**：CatmullRom 路径 × 三角带，uAdv 揭示推进 + uTime 流动虚线 + 尖端锥头贴路径滑行；撤退样式碎段虚线
- **阶段标签**：侧色底条文字精灵，进度阈值弹性弹出
- **特效**：交战火花（粒子环爆）+ 火攻（升腾火星羽流 + 橙色点光 + 地形 uFire 染色 + 全屏闪 + 相机震动衰减）+ 夜战（地形 uNight 染色注入 + 三灯联动 + 篝火/窗火 emissive 点亮）
- **测绘件**：程序化罗盘（指北针+四向刻度）与比例尺（按真实跨度换算 km，nice-number 取整）贴地放置
- **渲染管线**：edu-vfx 三行接入（illus 模式 + makeStudioEnvironment + 三灯布光）；验收钩子 `__warStats`（draw call）/`__warPickProbe`（拾取探针）
