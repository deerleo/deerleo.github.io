## 三、本轮修复的前段遗留 bug（playwright 实测揪出）

1. **`tl.set is not a function`（5 处，功能性硬伤）**：ch1 从头看一遍 / ch2、ch5 复位重种 / ch10 授粉结荚、回到开花全部抛错不生效——timelineCtl 只在 `slider` 上有 `set()`；改为 `tl.slider.set(x)`
2. **剖开豆荚整帧黑屏（NaN 几何）**：`makePodCutaway` 的 `Math.pow(Math.sin(...), 0.9)` 在 sin 为负时得 NaN → 顶点 NaN → computeBoundingSphere NaN 报错 + 整帧渲染黑屏；补 `Math.max(0, …)`（与 `makePod` 同款防护对齐）
3. **课堂模式出口被浮层盖住**：浮层（right:12px）与舞台工具钮同域，退出课堂按钮不可点；课堂态下工具钮移到舞台左上（`left:40px`）
4. **标签精灵喧宾夺主**：3D 文字标注 0.0042–0.0046 scale 出 1.7–1.9 世界单位宽（比植株还宽），ch0 默认机位下幼苗被「子叶（储存养分）」大字掩埋——全部压到 0.0022–0.0026；ch0 机位拉近（[1.42,0.88,1.95]→[0.02,0.42,0]）
5. **文案缺陷**：种皮说明里残留英文 "soaked"（改「浸泡一夜后变软易剥」）；HUD「干重」标签过长换行截断（缩短）；对原版 8 字滑窗散文命中 6 处全部改述（淀粉产物句 / 胚根句 / 暗处理句 / 酒精脱色句 / 干重标签 / 画质 tooltip）

另：`mergeBatched` 按 pea 终审提示重点复查——实现正确（`inv × matrixWorld` 烘焙回 root 局部空间，无双重变换）；全库无双重 `.tex` 写法。
