## 五、本轮修复的 bug（自检/playwright 抓出）

1. **MB 分布归一化系数错（旧线遗留）**：`fmax = 2σ²·e` 应为 `2σ²/e`——曲线峰值只有 13.5% 高， Ea 右侧阴影面积教学点不可读；300K 对比曲线同源修正。修正后曲线满高、阴影区清晰
2. **活塞组缺 y 偏移**：器皿落台后中心 cy=-0.8，活塞组仍停 y=0——滑板悬在器口上方穿帮；`gp.position.y = box.cy` 修复，56% 压缩实测滑板居中行程正确
3. **章 3 HUD 漏显示（本轮引入自查出）**：重写 enter() 时漏 `hud3.el.style.display=''`——对照实验计数无处显示；修复后「无催化/有催化/对照剩余」三读数回归
4. **活塞旋钮双旋转 + 误隐藏**：mesh 与 group 双重 rotation.z 叠加 + 草稿残留 `visible=false` 把整个旋钮藏掉；精简为单 group 旋转
5. **慢放双重 timeScale（旧线遗留）**：帧循环已按 timeScale 缩放 dt，UPD[6] 再乘一次——慢放 0.25× 实际跑 0.0625×；去除二次缩放，慢放语义归位
6. **刻度贴花出负档位**：循环 i≤6 生成 100…0、-20 七档；改 5 档（100~0）+ 缩小贴花（0.62→0.30 宽）+ 降不透明度（0.5→0.34）
7. **构图终审重调**：道具阵列原布位在画幅外（x 3.1~4.5 出锥）——重布到 x 2.2~2.7 / z -1.2~-2.0（远处置放，五档宽度全程可见）；ch1/ch4/ch6 机位重取（活塞端部入画）；ch3 章标签 x -2.35→-2.12 入画
8. **器壁奶白 / 托盘粉色反光**：玻璃 envMapIntensity 压 0.32、护柱/珠边减细降亮、托盘深色低金属度、加热条收细——玻璃反应器从「白笼」读回「玻璃」
9. 合规 3 处原版文案 8 字窗口逐字命中 → 全部改述（「变的只是单位体积里活化分子的个数」「最终都会走到同一个平衡状态」「最终汇入同一个平衡状态」），滑窗复验零命中
