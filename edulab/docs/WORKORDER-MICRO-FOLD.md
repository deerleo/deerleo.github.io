## 改造要求

1. **左栏折叠**：左栏顶部加折叠按钮（‹ 图标）。折叠态：左栏缩为 28px 竖条（只显示 › 展开按钮 + 竖排当前章序号如「03」，可选），中栏 3D 占据其空间。展开恢复 246px。
2. **右栏折叠**：右栏顶部加折叠按钮（› 图标）。折叠态：右栏缩为 28px 竖条（显示 ‹ + 当前章知识点标题竖排文字可选），中栏占满。展开恢复 352px。
3. **动画**：栏宽过渡 transition 0.3s ease（grid-template-columns 过渡或 width 过渡），折叠/展开平滑不跳变；3D canvas resize 跟随（现有 ResizeObserver 自动生效，确认即可）。
4. **状态记忆**：折叠状态写 localStorage（key 如 `micro.foldL` / `micro.foldR`），刷新后保持。
5. **专注模式统一**：现有「专注模式」按钮语义保留=双栏同时折叠；再次点击恢复两栏。两侧独立折叠按钮与专注模式状态互不冲突（如左已折+专注模式=只折右；退出专注=恢复进入前状态）。
6. **视觉**：折叠按钮 hover 态明显（背景高亮），折叠后 3D 区扩满时相机视野自动适配（现有逻辑应已支持，验证）。
7. **375px 移动端**：已是纵向堆叠，不需要此功能（桌面端 only，媒体查询外）。
