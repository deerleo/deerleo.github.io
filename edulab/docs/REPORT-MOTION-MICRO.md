## 二、续作修复清单（前次中断遗留 + 本轮加固）

1. **真 bug ×3**：
   - `matGlow` 在 edu-vfx.js 有导出但漏 import → fric 章电机 LED / pend 章气垫泵 LED 创建即 `matGlow is not defined`，**章 5/8 无法进入**（补入 import 列表）
   - `NT.lcd = makeLcd(...).tex` 把纹理而非 LCD 对象赋给 NT.lcd → newton 章读数刷新 `NT.lcd.set is not a function`（改为先赋对象再取 `.tex` 作 map）
   - `tpReset` 内 `REPLAY.apply = null` 把章节 enter() 设置的回放器清空 → 实验结束后擦洗/回放永远走「先跑完一次实验」分支（删该行，apply 由 enter() 生命周期管理）
2. **功能 1:1 补缺——图表擦洗回放**：原版 done 态全局交互「拖动图表可回放，按空格再做一次」缺失。本轮新增 SCRUB 模块：done/暂停态横向拖动数据坞任意图表 → 横轴位置映射到本次采样时长 → 二分定位采样帧 → `REPLAY.apply` 逐帧套回场景（位置/角度/读数），光标处浮 `t = x.xx s` 气泡，松手停帧；`setStatus('done')` 时任务提示同步切换为擦洗引导文案（对齐原版 idle/done 双态提示结构）
3. **合规改写 8 处**：原版整句逐字命中清零（「观察能量柱的此消彼长」「光电门 1/2 下落高度」「回放本次实验」「导出 CSV 数据」「收起 / 展开数据坞」及 2 处可见 title 提「原版」）；改写后 8 字级命中仅剩实验名「运动与力 · MotionLab」（heat「传热与物态变化 · HeatLab」先例同口径保留），5 字级剩余均为物理量/器材标准名（钩码质量 m、挡光片宽度 d 等，教材通用术语不可改写）
4. **十章相机重排**：7 个台面章原机位 z=7.4–9.6 在 FOV40 × 竖长画幅（中栏 842×~810，画幅比≈1.04）下 12 宽台面两侧出画（主体贴边/裁切）。按「半跨 ÷ tan20° ÷ 画幅比」重算机位距离（z=12.4–16.2）并压低机位高度让台面贴近画面中线；drop/lift/pend 三章构图已达标不动。逐章截图复检：台面全貌入画、水平居中、主体占比达标
5. **静态合并砍 draw call**：相机拉远后 free 台可见网格 132、calls 245–255 超 200 硬线。新增 `mergeStatics`（本地 `mergeGeoms` 索引几何拼接，零依赖免引 BufferGeometryUtils——本地 addons 未含该文件）：台面/道具/导轨等不动件按材质 bake 世界矩阵合并，`shadowBlob` 纹理/材质 mx 缓存共享；**全章 calls 降至 41–177**（ch10 245→177，ch01 77，ch05 64）。小车/光电门/挂钩等可动件不在合并范围，拖拽 raycast 零影响（实测 gate 拖动 g2x 1.2→2.10 生效）
