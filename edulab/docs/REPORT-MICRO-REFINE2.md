## 差距点 1：C 形镜臂曲线造型

**前**：镜臂是 2D Shape 沿直线路径挤出（等宽度 0.52 + 倒角），弯度较直、分件感弱，顶端与镜筒之间有 0.56 的 X 向悬空断裂。

**后**：
- `CatmullRomCurve3` 六点中心线（底座后部生根 → 后弯 → 背点 → 回弯前倾 → 顶端微内收），自研 sweep：沿曲线取 65 个 frame（宽度轴固定世界 X、深度轴取切线×X 叉乘），圆角矩形截面按关键帧 + smoothstep 缓动逐帧缩放缝合，端帽扇面封口（法线朝向自动翻转绕序）
- 三段质感分组（单 geometry 三 group 三材质，接缝共享顶点法线平滑）：根部金属套座（埋入基座）/ 中段奶油烤漆 clearcoat / 上端缎面金属托架
- 宽度节奏：根 0.38 → 握持段收窄至 0.225 → 顶端展宽 0.33；握持处外侧面橡胶内凹握垫（人机工学暗示）
- 新增横担托架（缎面金属）+ 枢轴轴座（镀铬，半埋镜筒）+ 锁紧螺钉，臂顶经横担→轴座与镜筒形成真实机械衔接；EDULAB 铭牌移至横担前面板（默认机位直读）
- 基座衔接处经三版迭代：深色金属段外露时在暖光下读成"黑牙缺口"，最终改为金属段全埋 + 基座顶面亮色金属圈套座（车削件观感，干净落位）

**截图结论**：03/23 侧视图 C 形大弯臂流畅、宽度渐变明显；02 特写三段质感分层可辨、握垫与横担/轴座齐全；50 特写根部经金属圈落座无缺口。

## 差距点 2：目镜视野真实质感

**前**：白底（#f2ede0）纯色平涂 + 干净黑字 e，只有离焦模糊与照明模式合成。

**后**（全在 canvas 渲染管线内，零 shader 改动、edu-vfx 零侵入）：
- **光锥渐晕**：聚光器光锥双层——中心暖白提升（径向渐变 source-over）+ 边缘暗角（multiply，`rgba(150,132,105)` 0→0.62），明场/相差全强度、暗场只留轻暗角（色温逻辑保留）
- **暖白照明**：明场底色 #f2ede0 → #fdf6e6，暗场/相差底色不变
- **字形墨迹画布**（glyphCanvas，按字符缓存，逐帧仅 drawImage）：两级柔焦晕染垫底（墨水浸润）+ 6 次微位移叠印（参差墨缘）+ 纤维纹理 source-atop（只染字形像素）+ 900 点 destination-out 针孔侵蚀（墨膜斑驳）；字母 e 与污点片 p 共用
- **载膜纤维**：256px 程序化纤维贴样（130 条弯折短纤维）整幅 multiply 平铺（α 0.06）
- **微尘与气泡**：固定种子 5 颗半透明微尘 + 2 个气泡环（内壁高光），随玻片移动（在样品变换内绘制，暗场反相后呈亮点符合物理）；counter/dust 两张读数/污点玻片自动跳过，不干扰读数题
- **半对焦双影**：钟形窗口（|Δfocus|≈3.2 峰值）内叠加偏移 1–1.8px、α 0.26 的无模糊重像；全焦与重糊自动消退，与现有非线性离焦联动

**截图结论**：eye-halffocus（focus=62, ideal=65）可见双影+渐晕+墨迹纹理+气泡尘埃齐全；eye-infocus（focus=65）双影消失、样本保持纹理；亮度采样中心→边缘落差约 17%（r=0.4 处）至 ~30%（近rim），叠加中心提升后视场对比约 35–45%，符合「~35%」要求。

## 差距点 3：道具精细度

**前**：瓶签平面藏在玻璃内侧不可见、液面为单一等径圆柱平顶、培养皿素玻璃、玻片盒 7 片素玻片无端部造型。

**后**：
- **试剂瓶**：标签改弧面圆柱贴片（贴合瓶身锥度，θ 居中 +0.9rad；文字天然正向），试剂名大字 + 浓度小字双行字号（`makeLabelTexture` 新增 `lineSizes` 可选参数，缺省行为不变向后兼容）；内液改双层圆柱（底部缓升段+主体）+ 液面圆片（低于瓶肩）+ 弯月面高光贴片；五瓶液色分明——蔗糖淡黄 / **碘液棕黄**（深色 + 自发光通道保色相，暖光下不被漂白）/ 亚甲基蓝深蓝 / 香柏油金黄 / 清水无色微蓝；瓶玻璃 opacity 0.4→0.3 减少洗白
- **培养皿**：皿盖独立微透明材质（opacity 0.22，皿身 0.4）；两只均带琼脂面（淡黄 + 程序化菌落斑点纹理 + 高光噪点），叠放保留
- **玻片盒**：薄盒体（高 0.12）+ 两端梯形轮廓挤出的斜切挡板（外低内高镜像）+ 侧挡板；内部 4 片玻片（玻璃片身 + 磨砂端）错位叠放；开盖态保留
- 45° 桌面视角下五张标签全部可辨认（20/31/60 特写验证）
