## 三、自查修复记录（本轮实测发现并修复）

1. **示波管描迹被磷光衬遮挡**：磷光圆盘误置于描迹画布之前（z 1.44 > 1.43）且不透明 → 屏面全黑无波形；移至画布后（1.418）修复，特写截图确认正弦描迹可见
2. **检流计表盘埋入壳体**：`roundedSlab` 倒角把壳体前脸推到 z+0.168，表盘（0.16）与表针被埋 → 壳深 0.3→0.26、表盘 0.16/表针 0.166/玻璃 0.174 露出 12mm，修复后表盘刻度/数字/表针全可读
3. **蹄形磁铁 U 形不可读**：首版轭铁宽 0.36 被极靴（1.7 宽）完全遮挡 → 轭铁加宽至 2.0–2.1、极靴缩至 1.5，红 U 从两侧清晰读出
4. **发电机顶部轭铁挡视线**：yokeTop 在默认机位遮挡转子 → 移除，仅保留轭背+底座；灯泡移位避开转子剪影
5. **ch6 导轨 +z 端悬空缺腿（存量 bug）**：补齐四腿 + 支脚
6. **「高频电源」文案与原版撞句**：改「射频电源」；全部新标识符对原版 dec/fields.js **0 命中**
