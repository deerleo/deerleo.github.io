## 具体做法

1. **目镜视野窗折叠**：
   - 窗体头部加折叠钮（− / + 或 ▾/▸）。折叠态：整窗收为一个 40px 圆形「目镜」小徽标按钮（图标显微镜目镜或「目」字），悬浮原位置；点击展开恢复
   - 折叠状态 localStorage 记忆（`micro.foldEye`）
   - 折叠时若正处目镜放大模式，自动退出放大
2. **右栏内手风琴**：
   - 「知识点详解」「实验控件」「数据读数」三块标题行加折叠箭头，点击收起该块 body（0.25s 动画）
   - 默认：详解展开、控件展开、数据读数展开；用户收起后 localStorage 记忆（每块一个 key）
   - 章节切换时**不重置**用户的手风琴偏好
3. **小屏联动策略**（≤1100px 宽）：目镜窗默认折叠、数据读数默认收起——首访小屏自动「清爽态」，用户手动展开后按记忆走
4. **通用折叠钮样式**：与现有栏折叠钮同款（fold-btn 风格统一），位置固定在面板右上角，hover 高亮
5. 折叠动画统一 0.25-0.3s ease；canvas/布局自适应沿用现有 ResizeObserver
