## 三、装配段收口（本会话核心工作）

前轮会话在 429 限额中断时六章 IIFE 已完成但 **boot 装配段缺失**（章注册/切章/折叠/键盘/RAF 全部未写，`CHAPTERS`/`perfNow`/`labelsOn` 悬空引用）。本会话补齐：

1. **装配段**：SECTIONS 注册 7 章 + 左栏列表（序号+中英标题+高亮迁移）+ setChapter（leave→enter→chrome 联动→acc-empty→scrollTop）+ gotoChapter 环绕
2. **自研随堂检测章**（QUIZ）：在台 quiz-card + 画布程序化配图垫底（谢尔宾斯基两层镂空/科赫两级对比/二叉树/蝴蝶结扭带示意/黄金矩形风车切割/240 粒黄金角螺线）+ 判分着色（correct/wrong）+ 解析 + 成绩页 + 中途切章恢复已判分态
3. **折叠体系**：左右栏 28px 竖条折叠（wonder.foldL/R）+ 右栏三手风琴（wonder.acc*，≤1100 首访读数默认收）+ 专注模式（双栏同折，Esc 退出恢复）——首访不写盘
4. **工具与键盘**：←/→/R（2D 章复用 lastFit 取景、莫比乌斯走 vfx 运镜）/T（纸面↔Studio 持久化）/F/空格（data-play）/Esc；◍ 标注开关（wonder.labels）
5. **主循环**：app.onFrame 驱动章 frame + composite2D（3D 由 edu-vfx 管线直出，attachVFX 接管运镜不再挂 cameraTweenTick）+ `__wonderStats` 性能钩子

**本会话修复的现场缺陷**：`applyStyle` 残留 `CHAPTERS` 未定义引用（换肤必抛错）；`perfNow` 悬空；2D 画布 z 序颠倒（被 WebGL 画布盖住全黑 → appendChild + z-index:2）；离屏墨点层 `inkResize` 从未被调用（墨点画飞）→ 挂入 resize()；quiz 配图 haloText 误传世界坐标 → 全部改 W2S 展开。
