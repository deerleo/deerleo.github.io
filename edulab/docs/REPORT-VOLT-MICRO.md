### 3.3 DIY 搭建器物理规则（自研增设的完整性）

- 过流烧毁：元件按各自额定（灯 0.6A/阻 2A/变阻 2A/电感 1.5A/二极管 1A/电机 2A）持续 0.6s 烧毁（3D 焦黑罩 + 清单标红）；短接线单挂即短路 → 保险丝 1.4×Ir 熔断（0.15s）——「先排除短路再修复」物理正确（修复前不移除短路则新保险丝再熔断，toast 引导）
- 电动机 = 绕组电阻 + 反电动势源串联（复刻教学章做法）+ 转子动画 + rpm 一阶趋近
- RC/LC 拓扑支持瞬态推进（CIR.dt=0.002 步进）

7. **CSS token 落空**：新增样式误用不存在的 `--fg/--panel/--panel-2` token → 全部落亮色 fallback（浅色主题下 off 态按钮文字几乎不可见）→ 批量换 `--text/--card/--bg-soft`（27 处）。
