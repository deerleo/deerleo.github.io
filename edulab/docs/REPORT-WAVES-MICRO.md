## 四、本轮修复的 bug（gate/目检抓出）

1. **roundedBoxGeo 参数序错位**（最重要）：实现签名 (w,h,r,depth) 而全部 33 处调用按 (w,h,d,r) 直觉书写——圆角半径远超高时 Shape 变花边，单摆底座「锚形黑翼」、共鸣箱扭曲、挡风玻璃花边同根因 → 重写实现为 (w,h,d,r) 语义（水平截面 + 竖直挤出 + 居中 + 圆角/斜边钳制），5 处旧序调用单独修正
2. **滑块 gbody 缺 depth 实参** → ExtrudeGeometry depth=undefined；补参
3. **量角器盘 bloom 炸白**：白色 MeshBasicMaterial 大面积 + bloom 阈值 0.86 → 改 Standard 材质 + 纸色降档 + 半径 0.34→0.26
4. **光电门眼睛被横臂块包住、数显字面朝侧面俯视不可读** → 横臂减薄 + 眼睛外露 (z+0.024) + 数显字面转朝上（rotation.x=-π/2 贴壳顶）
5. **质点振动图欠采样**：每帧只推 1 个历史点，软渲染 2-3fps 下 4.2s 仅 9 样本 → 改 while 循环按仿真时间补采样（与纸带同款）
6. **驻波弦/绳台绳与木台面对比不足** → 弦改 matGlow 发光材质（暖金/冷白），三章相机贴绳压低
7. **弹簧台/多普勒构图偏远** → ch0/ch2 相机压近（导轨满幅），ch8 相机压低（听者特写）
8. **装置漂浮感** → 六处台面接触阴影贴片（导轨/单摆/共振/珠列/绳台×2/共鸣管）
9. **音叉悬空** → 补立杆支架 + 领环
10. **合规 12 处 8 字命中**（两个章节标题 8-9 字 + 3 处正文/注释沿用原句）→ 全部改写至零命中
