## 四、本轮修复的 bug（gate/自检抓出）

1. **makeHUD 漏导入** → 模块加载即崩，boot 失败
2. **earthReady TDZ**：渲染钩子在模块求值期被触发，`let` 声明滞后 → ReferenceError；声明前置修复
3. **etaToMeters 被误删**（一次重命名 Edit 连带删除函数）→ 帧循环第 8 步每帧抛错、模拟时间冻结；恢复函数后 HUD/图表/海岸窗全部恢复实时
4. **海岸窗高度为 0**：内容全绝对定位缺 aspect-ratio → 窗体不可见；补 3/2 比例
5. **任务 chip 显示 [object Object]**：取 {t,key} 对象未取 .t 字段
6. **木船截面放样首版成「锅」**：环形截面 + 顶部回绕桥接把舱口盖死 → 改 U 形闭环截面（右舾→右舷→底→左舷→左舾顶→顶沿微下沉回程）+ CatmullRom 宽度包络收尖首尾 + 双舾缘 Tube 弯管
7. **道具落沙穿帮**：验潮桩/观测屋/石阵初版埋进沙面 → 按 ground(z)=0.1+0.16z+noise 逐件落地；船/浮标移到深水区随潮起落
8. **水面深度公式**：初版用 pre-wave 局部坐标 → 改片元内世界坐标推算（vWp2.y − ground(x,z)），岸线泡沫带位置与水位联动正确
9. **夜景过黑**：海边夜间主光/半球光下限提高（0.38/0.4），窗体自发光夜间拉亮
10. **章4 机位背对太阳**：初版从 -X 侧看夜面 → 改侧面机位（[1.5,6.5,23.5]），日月地连线横向入画、地球半昼面
11. **合规文案残留 8 处**：教学文案/shader 注释/控件标签沿用原版措辞（8 字滑窗命中 34 处）→ 全部改写至**零命中**
