## 四、建模深改清单（3+ 节六条逐项）

1. **主体建模**：原子金属/非金属双族材质分区；π 电子云瓣（键级≥2 挂半透明香肠瓣、三键补正交一组，随键生长/断裂同步缩放淡出）；孤对电子泪滴瓣（lp: 箭头出生点可见化）；电荷光环精灵（呼吸脉动）；过渡态虚线呼吸脉动；弯箭头自发光 + 锥头 + 键级变化按「旧淡出新长入」处理
2. **场景叙事**：木纹实验台（台面+前后封边）+ 每章手写粉笔方程黑板（自动折行 wrapEq + 擦痕/粉笔灰/搁槽/两截粉笔）+ 试剂瓶×2（弧面标签/内液/黄铜盖）+ 试管架×3 色 + 分子模型箱（铭牌+微开盖）+ 接触阴影（分子按包围盒摆位 + 道具各自投影）
3. **材质工艺**：全走 edu-vfx 工厂（matCoat/matStd/matGlow/matGlass）+ PAL 取色（π瓣 cytosolLit、孤对瓣 vesicle、键杆 steel、瓶盖 brass）；主体 clearcoat/sheen；发光件 emissive 与 bloom 联动
4. **光照氛围**：主暖光+冷补光+台面反弹+半球；makeStudioEnvironment 程序化环境反射；接触阴影贴片（无漂浮感）
5. **程序化纹理**：木纹/粉笔板/瓶签/阴影/光环全 CanvasTexture 程序化（见 §一 密度证据）
6. **互动可视反馈**：电子对粒子沿箭头曲线流动（速率随速度滑杆联动）；示踪开关原子实时变色+标签；步骤圆点/键盘步进实时跳转；速度滑杆→读数实时更新
