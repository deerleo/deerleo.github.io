## 背景

Leo 明确了布局语义，第一轮重构理解偏了。他要的不是「全屏 3D + 悬浮卡」，而是**经典三栏教学布局**：

```
┌──────────┬──────────────────────────┬──────────────┐
│ 左栏      │      中栏                │ 右栏          │
│ 章节列表  │      3D 显微镜展示        │ 知识点详解    │
│ (培训大纲)│   (点击左栏章节后         │ (当前章节的    │
│ 01 认识…  │    3D 飞到对应部位)       │  知识解释+    │
│ 02 规范…  │                          │  本章控件)    │
│ …16 章    │                          │              │
└──────────┴──────────────────────────┴──────────────┘
```

**交互语义**：
- 左栏 = 课程大纲：全部 16 章竖排列表（序号+标题），点击即切换到该章；当前章高亮
- 中栏 = 3D 舞台：切章时相机飞到该章对应部位（现有 setCamera 逻辑保留）
- 右栏 = 知识点面板：显示**当前选中章节**的知识详解正文 + 该章的交互控件（按钮/滑杆/toggle）+ 数据读数
- 例：左栏点「目镜与镜筒」→ 中间 3D 相机飞到镜筒特写 → 右栏显示目镜知识点详解 + 部件标注开关等控件
- 目镜视野圆窗：作为右栏的一个区块存在（有目镜视野的章节显示，如「规范操作」「观察步骤」章），或保留浮动在 3D 区右上角——按现有逻辑保留即可，但布局上不与右栏冲突

## 具体改造

1. **`micro/index.html`**：骨架改为三栏 grid：
   - `aside.lab-chapters`（左，宽 ~240px，可滚动）：顶部「课程大纲」标题 + 16 章列表（`<button data-idx>` 每章一项：序号 + 标题，当前章 `.on` 高亮态）

   - `aside.lab-detail`（右，宽 ~340px，可滚动）：章节标题 + 知识详解正文容器 + 控件容器 + HUD 读数区

2. **`assets/css/lab-micro.css`**：删除悬浮卡/毛玻璃卡样式，改三栏 grid 布局；深色主题延续；左右栏各自独立滚动；高度 100dvh 不出页面滚动条
3. **`assets/js/lab-micro.js`**：
   - 章节切换逻辑改为左栏列表驱动：点击列表项 → 高亮 + enter() 该章（现有 SECTIONS 数据全保留，enter() 里的相机飞行/控件生成照旧，只是控件渲染目标改为右栏容器）
