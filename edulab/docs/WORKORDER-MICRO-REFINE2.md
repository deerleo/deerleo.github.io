## 背景

第一轮精修后主控截图评审：布局与整体成品感已达标，剩三个具体差距点。本轮只攻这三点，改动范围仅 `assets/js/lab-micro.js`（如需目镜视野 shader 可小幅扩 edu-vfx.js，向后兼容）。

## 差距点 1：C 形镜臂曲线造型

现状：镜臂弯度较直、分件感弱。
原版观感：流畅的大 C 形弯臂，从底座后方向上再前倾抱住镜筒，臂身有宽度渐变（根部宽、握持处收窄、上端再展宽连接镜筒），表面哑光烤漆带高光走向。

做法要求：
- 用 CatmullRomCurve3 定义臂身中心线（底座后部 → 向上弯 → 顶部前倾抱镜筒），沿曲线放样变宽度截面（用自研 sweep：沿曲线取 N 个 frame，每个 frame 放置缩放不同的 RoundedBox/胶囊截面并 merge，或 TubeGeometry 自定义 radius function 的等价实现）
- 臂身分三段质感：根部底座连接件（金属深灰）、中段烤漆主体（同现有漆色+clearcoat）、上端与镜筒连接的托架
- 握持位置可加内凹弧（人机工学暗示）

## 差距点 2：目镜视野真实样本质感

现状：白底黑字 e，太干净。
原版观感：真实显微视野——照明不均（中心亮边缘暗的光锥渐晕）、样本有机细节、轻微离焦光晕、可能的微尘脏点。

做法要求（在目镜视野 canvas 渲染管线里加）：
- **光锥渐晕**：视野中央亮、边缘暗角过渡（径向渐变，亮度差 ~35%），模拟聚光器光锥
- **e 字样本升级**：字母边缘做墨水浸润感（边缘微噪点不规则化，用低频噪声扰动 alpha）；字内纤维纹理（细密随机短线，模拟纸/膜纤维）
- **微尘与气泡**：随机 3-6 个半透明微尘颗粒 + 1-2 个小气泡环（只装饰，不影响读数题）
- **离焦联动**：现有 focus blur 保持，但在半对焦时叠加轻微双影（ghosting：主像 + 偏移 1-2px 低透明度重像）
- **照明色温**：纯白改为暖白（#fff8ec 类调性），暗场/相差模式下色温逻辑保留

## 差距点 3：道具精细度

现状：瓶子无标签文字、液面平、培养皿素。
做法要求：
- **试剂瓶**：每个瓶身贴 CanvasTexture 标签（复用/扩展现有标签生成器）：试剂名中文（蔗糖溶液/碘液/清水/亚甲基蓝/香柏油）+ 浓度小字 + 简易边框线；瓶内液面用双层圆柱+液面圆片（液面低于瓶肩，带高光），碘液棕黄/亚甲基蓝深蓝/清水无色微蓝
- **培养皿**：叠放 2 只，上盖微透明（transmission 或 opacity 0.25），皿内琼脂面（淡黄圆片）
- **玻片盒**：开盖态，内部可见 3-4 片玻片叠放（薄盒体+端部斜切）
- 所有道具标签文字可读性以桌面视角 45° 俯瞰为准
