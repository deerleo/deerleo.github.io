## 四、本轮缺陷修复（自查发现，均 DOM 断言复验）

1. **特例标签永不隐藏**：`.hide` 在共享 CSS 无全局规则，`.orb-tag` 的 `display:inline-block` 使 hide 类无效 → 非特例元素也常显旧静态文案。修：`lab-orbital.css` 补 `.orb-tag.hide { display:none }` + selectElement 动态文案（Na 实测 display:none）。
2. **章 4/5 chips 残留**：能级/排布两章 enter 未调 syncChips，上一章速选 chips 滞留舞台 → 补调用（ch3/ch4 实测无残留）。
3. **道具朝向**：书脊标签与瓶签原朝向背对主视角 → 书堆 rotY +π、瓶签 thetaStart 转 +x 侧，主视角可读。
